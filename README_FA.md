# مسیریابی هوشمند در وستروس (AI Pathfinding in Westeros)

این پروژه شامل پیاده‌سازی الگوریتم‌های جستجوی آگاهانه و ناآگاهانه برای حل مسئله مسیریابی در یک محیط شبکه‌ای با تم سریال بازی تاج و تخت (وستروس) است. هدف، هدایت آریا استارک برای رسیدن به تمامی اهداف، با در نظر گرفتن موانع، هزینه‌های متفاوت زمین و دشمن متحرک (پادشاه شب) است.

## نمای کلی پروژه

محیط پروژه به صورت کاملاً مشاهده‌پذیر، قطعی، ترتیبی، ایستا و گسسته طراحی شده است که در آن عامل (آریا) باید برای جمع‌آوری چندین هدف ناوبری کند.

### اجزای اصلی

- **عامل (A):** آریا استارک که در چهار جهت اصلی (بالا، پایین، چپ، راست) حرکت می‌کند.
- **اهداف (T):** مکان‌های مشخصی که آریا باید به آن‌ها برسد.
- **دشمن (E):** پادشاه شب که در یک مسیر از پیش تعیین شده حرکت می‌کند. برخورد با او جریمه سنگینی دارد، مگر اینکه آریا سلاح داشته باشد.
- **سلاح (W):** خنجر از جنس فولاد والریایی. پس از جمع‌آوری، آریا می‌تواند در صورت برخورد با پادشاه شب، او را از بین ببرد.
- **انواع زمین‌ها:**
  - **برف:** زمین معمولی با هزینه عبور ۵.
  - **یخ (B):** زمین لغزنده با هزینه عبور بالای ۱۰۰.
  - **صخره/جعبه (R):** موانع غیرقابل عبور.

## الگوریتم‌های جستجو

در این پروژه الگوریتم‌های زیر پیاده‌سازی شده‌اند:

۱. **جستجوی اول سطح (BFS):**
   - **منطق:** لایه به لایه جستجو می‌کند تا کوتاه‌ترین مسیر از نظر تعداد گام را بیابد.
   - **ساختار داده:** **صف (Queue - FIFO)** (`collections.deque`).
۲. **جستجوی هزینه یکنواخت (UCS):**
   - **منطق:** گره‌ها را بر اساس کمترین هزینه تجمعی ($g(n)$) با در نظر گرفتن وزن زمین‌ها (برف و یخ) بررسی می‌کند.
   - **ساختار داده:** **صف اولویت‌دار (Priority Queue)** (`heapq`).
۳. **جستجوی عمق محدود (DLS):**
   - **منطق:** جستجوی اول عمقی که در یک عمق مشخص متوقف می‌شود تا از حلقه‌های بی‌نهایت جلوگیری کند.
   - **ساختار داده:** **پشته (Stack - LIFO)** (لیست پایتون).
۴. **جستجوی *A:**
   - **منطق:** از تابع $f(n) = g(n) + h(n)$ برای اولویت‌بندی گره‌ها استفاده می‌کند.
   - **ساختار داده:** **صف اولویت‌دار (Priority Queue)** (`heapq`).

### تحلیل هیوریستیک: چرا فاصله منهتن کافی نیست؟

اگرچه فاصله منهتن رایج است، اما در این پروژه به دو دلیل کارایی کمی دارد:
- **موانع:** صخره‌ها و جعبه‌ها را نادیده می‌گیرد و باعث تخمین بسیار کمتر از واقعیت می‌شود.
- **اهداف متعدد:** فقط نزدیک‌ترین هدف را در نظر می‌گیرد و حجم کار کل برای جمع‌آوری همه اهداف را نادیده می‌گیرد.

#### چرا MST و دایکسترا؟
برای ایجاد یک هیوریستیک با کارایی بالا:
- **درخت پوشای کمینه (MST):** برای تخمین کل هزینه مورد نیاز برای اتصال و بازدید از *تمام* اهداف باقی‌مانده استفاده می‌شود.
- **نقشه دایکسترا (Dijkstra Map):** فواصل واقعی کوتاه‌ترین مسیر بین نقاط را *با دور زدن موانع* پیش‌محاسبه می‌کند.

با استفاده از فواصل واقعی (به دست آمده از دایکسترا) به عنوان یال‌های یک درخت پوشای کمینه (MST) بین اهداف، به یک تابع هیوریستیک بسیار دقیق می‌رسیم که تعداد گره‌های بسط داده شده را به شدت کاهش می‌دهد.

## ساختار پروژه

- `main.py`: نقطه ورود برای اجرای شبیه‌سازی‌ها.
- `env/`: شامل منطق محیط بازی.
  - `domain.py`: تعریف `GameState` و منطق انتقال حالت.
  - `map.py`: مدیریت تجزیه و بارگذاری نقشه‌ها.
  - `constants.py`: ذخیره مقادیر پیکربندی مانند هزینه‌ها و پاداش‌ها.
  - `rendering.py`: مدیریت نمایش بصری با استفاده از کتابخانه Pygame.
- `search/`: شامل پیاده‌سازی الگوریتم‌های جستجو.
- `env/src/maps/`: شامل فایل‌های مختلف نقشه (آسان، متوسط، سخت).

## نحوه اجرا

۱. کتابخانه‌های مورد نیاز را نصب کنید:
    ```bash
    pip install -r requirements.txt
    ```
۲. پروژه را با دستور زیر اجرا کنید:
    ```bash
    python main.py
    ```

می‌توانید فایل `main.py` را برای تغییر نقشه یا الگوریتم جستجوی مورد استفاده ویرایش کنید.
